# VOID TD

Tower Defense для Roblox в стиле классических блочных TD: Пустота, тёмная магия, фиолетовый неон.
Всё — модели, карта, эффекты, UI — создаётся кодом, без внешних ассетов.

## Установка (Command Bar)

1. Открой новое место в Roblox Studio (шаблон Baseplate подойдёт — стандартный Baseplate удалится сам).
2. **View → Command Bar**.
3. Скопируй **весь** файл [`build/VoidTD_Installer.lua`](build/VoidTD_Installer.lua), вставь в Command Bar, нажми Enter.
4. В Output появится `[VOID TD] Установка завершена!`, а в Workspace — карта.
5. **Ctrl+S**, затем **Play**.

Если Command Bar не принимает большой файл — вставь по очереди три части из `build/parts/` (1 → 2 → 3).

Чтобы гемы и юниты сохранялись между запусками: *Game Settings → Security → Enable Studio Access to API Services*.
Без этого игра работает, но профиль каждый раз стартовый.

Альтернатива для Rojo: `rojo serve` (файл `default.project.json`).

## Как играть

1. Ты появляешься в **лобби** — отдельном парящем острове.
2. Встань в круг:
   - **2 кейса** (слева: VOID CASE, SHATTERED REALITY) — открытие кейсов за кристаллы, у каждого своя анимация
     (Blood Case убран из лобби и меню; его юниты остаются у игроков);
   - **HALLOWEEN EVENT** (огромный оранжевый портал) — телепорт на Хэллоуин-остров;
   - **ЮНИТЫ** (синий) — инвентарь и экипировка 6 слотов (ещё он всегда открывается кнопкой слева или `G`);
   - **ИГРАТЬ** (фиолетовый, у портала) — выбор сложности и вход в бой.
3. Сложности: **Лёгкая / Средняя / Сложная / Хардкор** (HP и скорость врагов, деньги, гемы, здоровье ядра).
   Если бой уже идёт — портал предложит присоединиться к нему.
4. После победы или поражения все возвращаются в лобби. Выйти раньше — кнопка «⟵ В ЛОББИ».

## Управление

| Действие | Клавиша |
|---|---|
| Выбрать юнита из хотбара | `1`–`6` или клик по слоту |
| Поставить | ЛКМ (с `Shift` — поставить несколько) |
| Повернуть | `R` |
| Отмена | `Q` / ПКМ / `Esc` |
| Выбрать поставленного юнита | клик по нему |
| Улучшить / продать / сменить цель | `E` / `X` / `T` (или кнопки на панели) |
| Инвентарь и экипировка | кнопка «☰ ЮНИТЫ» слева или `G` |
| Лёгкая / полная графика | кнопка «⚙ ГРАФИКА» справа сверху (сохраняется; на телефоне лёгкая по умолчанию) |

На телефоне: тап по земле двигает призрак, внизу кнопки PLACE / ROTATE / CANCEL.

## Что внутри

- **11 юнитов, 5 редкостей** (Common 3, Rare 2, Epic 2, Legendary 2, Mythic 2), у каждого 5 уровней — модель меняется на каждом уровне.
- **Типы атак:** Melee, Projectile, Laser, AOE, Multi-Hit, Damage over Time (чёрная дыра).
- **Способности:** Eclipse Shockwave (настоящий AOE, каждый враг получает урон один раз за удар), Fallen Beam, Void Judgement, Black Hole (замедление + периодический урон, своя перезарядка).
- **Цели:** First / Last / Strongest / Weakest / Closest.
- **9 врагов** с броней, уклонением, разными размерами и наградами; боссы на 10, 20 и 30 волне (The Entity призывает миньонов).
- **30 волн**, таймер между волнами, кнопка Start Wave, победа/поражение и авторестарт.
- **Лобби** с кругами SUMMON / ЮНИТЫ / ИГРАТЬ, порталом и статуями героев.
- **4 сложности**, выбор при входе в бой.
- **23 юнита, 3 кейса** (x1 / x10 с гарантией Rare+). VOID CASE — 11 оригинальных юнитов; SHATTERED REALITY и BLOOD MOON — по 6 новых, включая редкость **SECRET (0.1%)**: Reality Destroyer (RED SPLASH) и Crimson Eclipse (BLOOD MOON).
- **Магазин кристаллов** (кнопка справа): 5 наборов за Robux + бесплатный подарок раз в 20 часов. Robux-товары: впиши ID Developer Products в `Config.Shop[...].ProductId`. Пока ID = 0, в Studio покупка бесплатная (тест).
- **Инвентарь**, **экипировка** 6 слотов, сохранение в DataStore. При улучшении меняется и материал брони: потёртый → металл → блестящая фольга с оттенком редкости.
- **Свои звуки**: 22 синтезированных эффекта в `assets/sounds` (wav + ogg, генератор `tools/make_sounds.py`). Загрузи их в Roblox (Creator Hub → Development Items → Audio) и вставь ID в `Config.Sounds[...].Custom` как `"rbxassetid://123"`. Пока поле пустое, играет встроенный звук Roblox.
- Чёрный экран-переход при входе в бой и возвращении в лобби, тряска камеры от боссов и ударов.
- Анимации: атаки у каждого юнита, действия в простое (вращение оружия, осмотр, разминка, перезарядка), приземление при установке,
  поза при улучшении, празднование после волны, развевающиеся плащи, кольца из вращающихся деталей, слежение за врагами;
  враги поднимаются из портала, отшатываются от ударов, боссы ревут при появлении.
- **Стиль моделей:** угловатая броня как на концепте — блоки с фаской и светлым кантом, клинья-шипы, кристаллы-ромбы, рваная ткань, цепи (общий модуль `ModelKit`). Void Knight уже переделан по концепту (5 уровней).
- **Интерфейс:** магазин, юниты и графика — квадратные иконки справа на экране.
- **Юниты:** все 23 переделаны в R6-стиле по референсу (блоки с фаской, броня, капюшоны, шлемы, плащи, оружие из блоков — почти без круглых деталей), внешний вид меняется с уровнем. Blood Moon по референсу: Blood Initiate, Scarlet Hunter (лук), Crimson Witch, Blood Paladin, Moon Devourer, Scarlet Eclipse — изменены только имена и внешний вид, характеристики прежние.
- **🎃 CURSED CLOCKMAKER (Проклятый часовщик, SECRET, Halloween):** голова — механические часы, Хроносекира с двумя зубчатыми лезвиями, 5 уровней внешнего вида.
  Атака «Разрез секунд» — зубчатый диск летит по прямой и режет до 5 врагов.
  «Поломка времени» — каждая 8-я атака (не чаще 18 с): до 4 врагов замирают на 1,5 с (боссы 0,5 с), до 3 откатываются на 2 studs.
  «Ускорение времени» — через 30 с и каждые 30 с: свои юниты в радиусе 14 атакуют на 6–10% быстрее 2–4 с (не стакается, сам себя не ускоряет).
  «Временная буря» — через 90 с: 15 с каждая атака бьёт по области (цель 100%, до 4 врагов рядом по 50%), перезарядка 90 с после окончания.
  В 3D-просмотре есть кнопки трёх способностей. Выпадает из Halloween Case (0.2%); в Studio часовщик выдаётся для проверки.
- **Меньше неона:** приглушены светящиеся детали, подсветка и Bloom.
- **3D-просмотр юнита:** клик по открытому юниту в инвентаре открывает большое окно — модель на платформе (ViewportFrame + WorldModel), вращение мышью/пальцем, зум колесом/щипком, автоповорот, анимации (Idle / Атака / Поза), переключатель LVL 1–4 / MAX (ничего не покупает), урон, радиус, скорость атаки, стоимость, способности, кнопка экипировки. Подсветка по редкости, частицы у мифических, короткое появление у секретных. Esc или клик по фону — закрыть.
- **Враги (визуальное обновление, этап 1):** 9 новых моделей с отдельной походкой для каждого типа
  (парение, бег на 4 лапах, галоп, тяжёлый шаг с тряской камеры), вторичным движением (хвосты, цепи,
  плащ, кольца, парящие осколки, дёрганая голова), своим появлением и своей смертью (растворение,
  разлёт частей, подкашивание лап, падение, коллапс финального босса).
  Боссы: вспышка портала и волна энергии при появлении. Corrupted Titan — повреждения на 50% HP,
  Void Devourer — трещины на 66% и отпадающая броня на 33%, The Entity — 3 фазы (65% / 30%):
  трещины и свечение, затем ломаются корона и кольцо. Фазы чисто визуальные, хитбоксы не меняются
  (урон считается сервером по пути, модель на попадания не влияет).
- **Карта The Forgotten Realm:** парящий остров, извилистая дорога, портал, ядро, кристаллы, руины, колонны, деревья, парящие островки, туман и освещение.
- Вся логика урона — на сервере. Клиент только рисует: модели, анимации (Motor6D), эффекты, полоски HP.

## Баланс

Все цифры — в [`src/ReplicatedStorage/VoidTD/Config.lua`](src/ReplicatedStorage/VoidTD/Config.lua):
урон/дальность/перезарядка/цены по уровням, враги, состав волн, деньги, шансы Summon.
Сложности — таблица `Config.Difficulties`. Общий множитель HP врагов — `Settings.EnemyHealthMult`.

Симуляция ботом (средняя игра, без микроконтроля), сильный состав (Legendary + Mythic):
Лёгкая и Средняя — победа, Сложная — до ~25 волны, Хардкор — до ~14 (живому игроку легче, чем боту).
Только Common-юниты на Средней доходят примерно до 24-й волны.

После правок в `src/` пересобери установщик: `python3 tools/build_installer.py`.
