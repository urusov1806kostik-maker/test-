# Посёлок: Линия фронта

3D-шутер в браузере (Three.js): пехота, БТР, FPV-камикадзе и разведывательные дроны.

Запуск: открыть `index.html` в Chrome/Firefox (нужен интернет для загрузки Three.js с CDN) или `python3 -m http.server` и зайти на http://localhost:8000.

Управление — в главном меню игры.
