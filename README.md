# Линия фронта

Браузерная стратегия в реальном времени: Украина против России.

Открыть `index.html` в браузере — установка не нужна.

## Что есть
- **Выбор стороны** и сложности ИИ (легко / нормально / сложно).
- **Постройки**: главный штаб, завод (бюджет), НИИ (наука), казарма, бронезавод, цех дронов, ДОТ, ПВО, РЭБ.
- **Дерево исследований** в стиле War Thunder: 6 веток (пехота, бронетехника, артиллерия, дроны, ПВО и РЭБ, экономика), ранги I–IV.
- **Дроны**: разведчик, FPV-камикадзе, бомбер, перехватчик, дальний ударный. РЭБ их глушит, ПВО сбивает, оптоволоконные FPV не глушатся.
- **Техника**: БМП, танки трёх рангов, САУ, РСЗО, мобильный ЗРК.
- Туман войны: артиллерия бьёт только по разведанным целям.
- **Реальная карта**: Украина и юг России — границы, Днепр, Донец, Дон, Чёрное и Азовское моря, Крым, города, примерная линия фронта. Штабы в Киеве и Ростове-на-Дону, наземные войска не ходят по морю.

## Управление
- Карточка снизу → клик по своей зоне — постройка.
- Рамка — выделить войска, клик по карте — приказ идти.
- `F` атака · `G` оборона · `Q` выбрать всех · `R` исследования · `Пробел` пауза · `Esc` отмена.

Цель — уничтожить главный штаб противника.
