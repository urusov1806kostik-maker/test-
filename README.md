# Shadow Visuals

Клиентский визуальный мод для **Minecraft 1.21.11 (Fabric)**: собственный ClickGUI, HUD с редактором, визуальные модули, камера, интерфейс и FunTime Helper. Всё работает только на клиенте и ничего не меняет на сервере.

## Требования

| | Версия |
|---|---|
| Minecraft | 1.21.11 |
| Fabric Loader | 0.19.5+ |
| Fabric API | 0.141.6+1.21.11 |
| Java (игра) | 21+ |
| JDK (сборка) | 25 (требование Fabric Loom 1.18) |

## Установка

1. Установите Fabric Loader и Fabric API для 1.21.11.
2. Положите `shadow-visuals-<версия>.jar` в папку `mods`.
3. В игре нажмите **Right Shift**, чтобы открыть меню. Клавишу можно поменять в разделе «Настройки».

## Возможности

- **ClickGUI**: боковая навигация, карточки модулей, панель настроек, поиск по названию, описанию и категории, избранное, контекстное меню, color picker (HSV, alpha, HEX, радуга), подсказки, анимации открытия и закрытия.
- **HUD**: Watermark, FPS, Ping, Coordinates, BPS, Keybinds, Active Modules, Potion Effects, Armor, Inventory, Target HUD, Session Info, Server Info, Compass.
- **Редактор HUD**: перетаскивание, масштаб колесом, привязка к краям и элементам, сброс позиций. Элементы не уходят за экран.
- **Visual**: Player ESP, Name Tags, Item ESP, Container Visuals, Block Outline (обводка и заливка), Glint Color, FullBright, Fire Overlay, Overlay Control, Particles.
- **Player**: Jump Circle, Trails, Hit Particles, Hit Sound, Hit Color, View Model, Swing Animation.
- **World**: Time Changer, Weather, Fog, World/Sky/Ambient Color, Waypoints, Death Point.
- **Camera**: Zoom (C), FreeLook (Left Alt), дистанция третьего лица, Hurt Camera, View Bobbing, FOV.
- **Interface**: прицел, хотбар, скорборд, Tab, боссбар, чат, подсказки.
- **FunTime Helper**: счётчики тотемов, жемчуга и кристаллов, свои счётчики любых предметов, кулдауны (только достоверные клиентские данные), предупреждения (здоровье, прочность, нет предмета, кулдаун готов), бинды предметов (Дезориентация, Пласт, Трапка, Явная пыль, Огненный смерч).
- **Utility**: Recording Mode скрывает ник, координаты, адрес сервера и приватные элементы HUD.
- **Темы**: 5 тёмных пресетов, каждый цвет настраивается, изменения применяются сразу.
- **Языки**: English, Русский, Українська, или «Авто» по языку игры.
- **Доступность**: полные, сокращённые или выключенные анимации, масштаб интерфейса, размер текста, высокий контраст, звуки интерфейса с регулировкой громкости.

## Конфигурация

Файлы лежат в `.minecraft/config/shadowvisuals/`:

| Файл | Содержимое |
|---|---|
| `client.json` | Общие настройки: язык, доступность, клавиша меню, последняя страница |
| `profiles/<имя>.json` | Профиль: модули, настройки, бинды, тема, позиции и масштаб HUD |
| `friends.json` | Список друзей |
| `waypoints.json` | Метки всех миров |

- Изменения сохраняются автоматически с задержкой (debounce), не чаще раза в 1,5 с.
- У файлов есть версия схемы, старые конфиги мигрируются.
- Повреждённый файл сохраняется как резервная копия, после чего загружаются настройки по умолчанию; игра не падает.
- Профили создаются, загружаются, переименовываются, дублируются и удаляются (с подтверждением) на странице «Конфиги».

## Сборка

```bash
export JAVA_HOME=/path/to/jdk-25
./gradlew build                 # jar в build/libs/
./gradlew test                  # юнит-тесты
./gradlew runClient             # запуск игры с модом
./gradlew runClientGameTest     # сквозной тест в реальной игре со скриншотами
```

Сквозной тест (`src/gametest`) запускает игру и проверяет:

- GUI на всех страницах, поиск, редактор HUD;
- масштабы GUI, полноэкранный режим, изменение размера окна, перезагрузку ресурсов;
- смерть, респавн и точку смерти, переход в Незер;
- второй мир, вход на выделенный сервер, Tab, выход и переподключение;
- бинды предметов.

Скриншоты сохраняются в `build/run/clientGameTest/screenshots/`. Без монитора тест запускается через `xvfb-run -a ./gradlew runClientGameTest`.

## Структура

```
dev.shadowvisuals
├── ShadowVisuals        точка входа Fabric, регистрация колбэков
├── ShadowClient         контейнер сервисов и жизненный цикл
├── core                 настройки клиента, сессия, логирование, звуки
├── event                шина событий и события (tick, render 2D/3D, ввод, мир)
├── module               Module, ModuleManager, категории
├── setting              типы настроек и их сериализация
├── config               файлы, миграции, профили, автосохранение
├── render               Renderer2D, WorldRenderer3D, проекция, шейдеры, SDF-шрифт
├── animation            анимации на delta time и easing-функции
├── theme                дизайн-токены и темы
├── ui                   компоненты, оверлеи, ClickGUI, экраны
├── hud                  HudModule, HudManager, замена ванильного HUD
├── modules              все модули по категориям
├── mixin                минимальные миксины
└── i18n, friend, waypoint, notification, util
```

### Как добавить модуль

1. Создайте класс-наследник `Module` (или `HudModule` / `PanelHudModule` для элемента HUD) в нужном пакете `modules/<категория>`.
2. Объявите настройки через `settings().add(...)`, подпишитесь на события через `on(Event.class, handler)`. Подписки активны только пока модуль включён.
3. Если модуль меняет состояние игры, верните его в `onDisable()`.
4. Зарегистрируйте модуль в `modules/ModuleCatalog`.
5. Добавьте строки `module.<id>.name`, `module.<id>.description` и `setting.<id>` во все файлы `assets/shadowvisuals/i18n/*.json`. Тест `shippedLanguagesDefineTheSameKeys` проверяет, что набор ключей во всех языках совпадает.

### Как добавить язык

1. Добавьте файл `assets/shadowvisuals/i18n/<код>.json` с теми же ключами, что в `en_us.json`.
2. Добавьте константу в `Localization.Language`. Недостающие строки берутся из английского.
