# 💸 Moneycode

Личный ИИ-агент: видит экран, кликает, печатает, запускает команды, работает с файлами, ходит по сайтам и пишет в Instagram, ищет в интернете, запоминает тебя.

## Установка (Windows)
1. Поставь Python 3.10+ с python.org (галочка «Add to PATH»).
2. Получи API-ключ: https://console.anthropic.com → API Keys.
3. В папке проекта:
```
pip install -r requirements.txt
playwright install chromium
setx ANTHROPIC_API_KEY "sk-ant-..."
```
4. Перезапусти терминал и запусти `start.bat` (или `python moneycode.py`).

## Отдельная программа (.exe)
Двойной клик по `build_exe.bat` → через пару минут получишь `dist\Moneycode.exe`.
При первом запуске exe спросит API-ключ и сохранит его в `config.json` рядом с собой.
Браузер для Инсты — твой Edge (есть в любом Windows), отдельный профиль.

## Примеры задач
- «Открой инсту, зайди в директ и ответь Саше: буду в 7»
- «Найди в интернете курс доллара и запиши в файл kurs.txt на рабочем столе»
- «Создай папку Проекты и сделай там сайт-визитку»
- «Запомни: меня зовут Костя, я делаю ботов»

## Обучение
- `knowledge.md` — вшитая база знаний (Windows, Instagram, код, безопасность).
- `memory.json` — что агент знает о тебе.
- `lessons.md` — уроки из опыта: после каждой задачи агент записывает, что сработало. Чем больше работает — тем умнее.
- `/train 10` — агент сам проходит тренировочные задания (комп, Инста, браузер, код) и копит уроки. `/train 50` — дольше, `/train 0` — бесконечно, пока не нажмёшь Ctrl+C.
- `/lessons` — посмотреть уроки, `/mem` — память.

## Безопасность
- По умолчанию спрашивает разрешение перед командами, записью файлов и отправкой сообщений. Отключить: `set MONEYCODE_SAFE=0`.
- Мышь в левый верхний угол экрана — аварийная остановка.
- Автоматизация Instagram нарушает их правила: не спамь, иначе аккаунт могут заблокировать.
