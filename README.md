# Линия фронта

Тактическая стратегия в реальном времени на реальной карте Украины и юга России. Открыть `index.html` в браузере — установка не нужна.

## Что есть
- **Реальная карта**: границы, Днепр, Донец, Дон, Чёрное и Азовское моря, Крым, ~30 городов, примерная линия фронта. Территории сторон, строить можно только на своей.
- **Города** дают бюджет. Ударные дроны («Лютый» / «Герань-2») бьют по ним роями — прикрывайте ПВО.
- **ПВО и РЛС**: РЛС видит дроны и самолёты далеко, зенитные комплексы с ограниченным запасом ракет, дальний ЗРК (Patriot / С-400), склад боеприпасов и инженеры пополняют ракеты. РЭБ глушит дроны. Воздушная тревога с сиреной.
- **Авиация**: аэродром, истребители (F-16 / Су-35) сами взлетают на перехват, расходуют топливо и ракеты, садятся на дозаправку. Штурмовики Су-25.
- **Дроны**: разведчик, FPV, бомбер, перехватчик, дальний ударный. Мобильные огневые группы.
- **Дерево исследований** в стиле War Thunder: 7 веток, ранги I–IV.
- Свой набор иконок, тактические знаки (`T`), туман войны, зум и миникарта, синтезированный звук, режим песочницы.

## Управление
- Карточка снизу → клик по своей территории — постройка.
- Рамка — выделить войска, клик — приказ идти.
- Колесо — масштаб, `WASD`/стрелки или средняя кнопка — движение карты.
- `F` атака · `G` оборона · `Q` все войска · `R` исследования · `T` тактические знаки · `M` звук · `Пробел` пауза.

Цель — уничтожить главный штаб противника.
