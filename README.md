# Pitbike (Forge 1.20.1)

Заспавнить в креативе: вкладка «Инструменты и приспособления», или `/give @s pitbike:pitbike`, или `/summon pitbike:pitbike`.

Мод добавляет ездовой питбайк-ентити из модели `model_src/pitbike.bbmodel`.

- Предмет «Питбайк» — вкладка «Инструменты и приспособления». ПКМ по блоку — поставить, ПКМ по байку — сесть, Shift — слезть.
- Крафт (открывается, когда есть поршень):
  ```
  . . палка
  фиол.краситель поршень фиол.краситель
  железо . железо
  ```
- W/S — газ/тормоз/назад, A/D — поворот (рулит только на ходу).
- Во время езды играет анимация `ride`: её скорость привязана к скорости байка, так что колёса крутятся в такт земле, а при езде назад — в обратную сторону. `ride_forward` не используется.
- Пробел + W — езда на заднем колесе (вилли), байк и райдер задираются вместе.
- Трамплины подкидывают байк. В воздухе — трюки (клавиши меняются в настройках управления, раздел «Трюки на питбайке»):
  | Клавиша | Трюк | Очки |
  |---|---|---|
  | Z | Ванхенд | 100 |
  | X | Ноухенд | 150 |
  | C | Супермен | 250 |
  | V | Бэкфлип | 400 |
  | B | 360 | 300 |

  Несколько трюков за прыжок — комбо (очки × число трюков). Приземлился, не докрутив, — падаешь с байка.
- `/pitbike city` — строит вокруг тебя стант-город 92×92 (дороги, дома, скейт-плаза с фанбоксом и кикерами, руфтоп-прыжок с крыши на крышу, мега-рамп через дорогу) и ставит на старт перед мега-рампом.
- В креативе ломается с одного удара.
- В поворотах байк наклоняется вместе с райдером, из глушителя идёт дым, справа от хотбара показан спидометр (км/ч).
- Звук мотора: тон и громкость растут со скоростью (генерируется `tools/gen_engine_sound.py`).
- У каждой части свой хитбокс (колёса, маятник, амортизатор, двигатель, рама, сиденье, бак, вилка, крыло, руль, глушитель). F3+B — показать хитбоксы. Двигатель и бак получают ×1.5 урона, колёса ×0.75.
- В выживании — 20 HP, при поломке выпадает предмет.

## Сборка

```
./gradlew build
```
Jar: `build/libs/pitbike-1.0.0.jar`.

## Обновление модели

Модель mesh-овая (GeckoLib такие не поддерживает), поэтому рендер свой. После правки `.bbmodel`:

```
python3 tools/convert_bbmodel.py   # нужен Pillow
```
Скрипт пересобирает геометрию, анимации, атлас текстур и иконку предмета в `src/main/resources/assets/pitbike/`.
