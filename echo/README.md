# E.C.H.O — голосовой ИИ-помощник для Windows 10/11

Python + PySide6 + SQLite + Claude API. Мужской нейронный голос (Microsoft Dmitry), голосовая активация словом «Эхо», управление ПК, Steam, Telegram, Discord, Vision, Security.

## Установка без exe (проще всего)

1. Установите **Python 3.12** с python.org (галочка «Add Python to PATH»).
2. Дважды щёлкните **`install.bat`** в папке `echo`. Он поставит зависимости и создаст ярлык **E.C.H.O** на рабочем столе.
3. Запускайте ярлыком: консоль не открывается. Папку `echo` после установки не удаляйте и не перемещайте.

## Установка через ECHO_Setup.exe

1. Запустите `ECHO_Setup.exe` → отметьте «Создать ярлык на рабочем столе» (и при желании автозапуск).
2. Откройте E.C.H.O ярлыком → **Настройки → API-ключ** → вставьте ключ с [console.anthropic.com](https://console.anthropic.com) → «Сохранить» → «Проверить».
3. Скажите: **«Эхо, привет»**.

Ключи и токены хранятся в Диспетчере учётных данных Windows (keyring), а не в файлах. Настройки, история и память лежат в `%APPDATA%\ECHO`.

## Сборка ECHO_Setup.exe (один раз, на Windows)

1. Установите **Python 3.12** с python.org (галочка «Add Python to PATH»).
2. Установите **Inno Setup 6** (https://jrsoftware.org/isdl.php). `build.bat` попробует поставить его сам через winget.
3. Дважды щёлкните **`build.bat`**. Результат:
   - `dist\ECHO\ECHO.exe` — программа;
   - `dist\ECHO_Setup.exe` — установщик.

Запуск из исходников без сборки: `run_dev.bat`.

## Голос

| Фраза | Что происходит |
|---|---|
| «Эхо, …» | команда или вопрос; следующие ~25 с можно говорить без «Эхо» |
| «Эхо, давай поговорим» | режим беседы, «Эхо» говорить не нужно |
| «Эхо, закончи разговор» | выход из режима беседы |
| «стоп» / любая фраза во время ответа | перебить E.C.H.O |
| «да» / «нет» | подтвердить или отменить опасное действие |

- Конец фразы определяется по паузе (VAD webrtcvad, настраивается).
- Подавление эха: во время своей речи порог микрофона выше, а распознанные фразы, совпадающие со сказанным самим E.C.H.O, отбрасываются. Лучше всего работает в наушниках.
- Распознавание: Google (онлайн) или Vosk (полностью локально, модель скачивается кнопкой в настройках).
- Голоса: Дмитрий (по умолчанию), любые нейронные голоса Microsoft («Ещё голоса…»), офлайн-голос Windows SAPI. Скорость и громкость настраиваются.

## Как E.C.H.O отличает разговор от команды

Claude получает действия как инструменты (tool use) и вызывает их, только когда вы явно просите сделать что-то сейчас. «Давай КС» запускает игру, а «я вчера играл в КС» — это просто разговор. Закрытие программ и игр, выключение ПК, отправка сообщений, клики мышью и ввод текста — только после подтверждения.

Без интернета или ключа работают локальные команды: «открой ютуб», «запусти кс», «громкость 30», «тише», «пауза», «следующий трек», «скриншот», «открой загрузки», «закрой хром», «напомни через 10 минут …», «нагрузка системы».

## Модули

- **AI Chat**: текстовый чат с общей с голосом историей, стриминг, плавное появление ответов.
- **Memory**: история и долговременные факты (ИИ запоминает сам, можно добавить или удалить вручную).
- **Vision**: анализ экрана через Claude (текст, ошибки, кнопки). Клики мышью — только если включено в настройках, и каждый с подтверждением.
- **Steam**: игры находятся через `libraryfolders.vdf`; доступны запуск, список, запущенные игры, закрытие.
- **Управление ПК**: программы из меню «Пуск», реестра и ярлыков; громкость (pycaw), медиа-клавиши, окна, скриншоты, поиск файлов, папки, тёмная тема, яркость, разделы настроек, блокировка и питание.
- **Security**: Microsoft Defender (статус, быстрая и полная проверка, проверка файла, журнал угроз), подозрительные процессы, автозагрузка.
- **System Monitor**: CPU, RAM, диск, GPU (NVIDIA через nvidia-smi). Температура CPU — при запущенном LibreHardwareMonitor.
- **Live Translate**, **Reminders**, **Custom Commands / Smart Actions**, **Gaming Mode**, **Web Search** (встроенный поиск Claude + открытие Google), **File Manager**.
- **Telegram**: официальный API (Telethon). Нужны `api_id`/`api_hash` с my.telegram.org, вход по коду. Можно читать, делать пересказ, искать контакты, открывать чаты, озвучивать уведомления; отправка — только с подтверждением.
- **Discord**: официальный Bot API. Личный аккаунт автоматизировать нельзя (self-bot запрещён правилами Discord), поэтому бот видит только серверы, куда его добавили. В Developer Portal включите Message Content и Server Members Intent.

## Структура

```
main.py                  точка входа
echo_app/assistant.py    ядро: Claude, tool use, стриминг, подтверждения, режимы
echo_app/tools.py        все действия для ИИ
echo_app/localcmd.py     офлайн-команды
echo_app/voice/          tts.py, stt.py, listener.py (wake word, VAD, перебивание, эхо)
echo_app/pc.py apps.py steam.py security.py sysmon.py
echo_app/integrations/   telegram.py, discord_bot.py
echo_app/ui/             интерфейс PySide6
installer/               echo.spec (PyInstaller), echo.iss (Inno Setup)
build.bat                сборка exe и установщика
```

Лог: `%APPDATA%\ECHO\echo.log`.
