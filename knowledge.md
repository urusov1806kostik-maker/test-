# База знаний Moneycode (вшита в программу)

## Общий подход
1. Пойми цель. Если задача неясна — задай ОДИН короткий вопрос, иначе делай.
2. План из 2–6 шагов в голове, потом действуй.
3. После каждого действия проверяй результат (read страницы, скриншот, вывод команды). Не считай, что сработало, пока не увидел.
4. Не получилось 2 раза одним способом — смени способ (селектор → текст → координаты → клавиатура).
5. В конце — коротко: что сделал и что получилось. Без воды.

## Выбор инструмента
- Сайт/Инста/почта в браузере → `browser` (надёжнее, чем мышь по экрану).
- Программы Windows (Блокнот, Проводник, Telegram Desktop, игры) → `screenshot` + `mouse` + `keyboard`.
- Файлы, папки, установка, системная инфа → `run_command` (быстрее, чем кликать).
- Факты из интернета, курсы, новости → `web_search`.

## Windows: полезные команды (run_command, это cmd)
- Рабочий стол: `%USERPROFILE%\Desktop` (если OneDrive — `%USERPROFILE%\OneDrive\Desktop`, проверь `dir`).
- Открыть программу/файл/сайт: `start "" "путь_или_url"`; Блокнот: `start notepad`.
- Список файлов: `dir /b "путь"`; поиск: `dir /s /b "C:\Users\%USERNAME%\*.pdf"`.
- Создать папку: `mkdir "путь"`; копировать: `copy`/`xcopy /e /i`; переместить: `move`.
- PowerShell внутри cmd: `powershell -NoProfile -Command "..."`.
- Инфа о системе: `systeminfo`, процессы: `tasklist`, закрыть: `taskkill /im имя.exe /f` (спроси перед этим).
- Сеть: `ipconfig`, `ping -n 3 google.com`.
- Установка программ: `winget install --id <ID> -e` (найти ID: `winget search имя`).
- Скачать файл: `powershell -c "Invoke-WebRequest URL -OutFile путь"`.
- Кодировка: если в выводе кракозябры — `chcp 65001 >nul & команда`.

## Windows: горячие клавиши (keyboard keys=[...])
- Пуск/поиск: `["win"]`, потом печатай название, `["enter"]`.
- Копировать/вставить/вырезать: ctrl+c / ctrl+v / ctrl+x; отменить ctrl+z; всё ctrl+a; сохранить ctrl+s.
- Переключить окно: alt+tab; закрыть окно: alt+f4; свернуть всё: win+d; проводник: win+e.
- Скриншот области: win+shift+s. Адресная строка браузера: ctrl+l. Новая вкладка: ctrl+t.

## Работа с экраном

- Список длинный — `mouse action=scroll` (минус = вниз).

# TikTok: как набирать просмотры и зарабатывать
ВАЖНО: условия TikTok (монетизация, страны, возраст, пороги подписчиков/просмотров) часто меняются.
Перед советами про деньги ВСЕГДА проверяй актуальное через web_search («TikTok Creator Rewards requirements <год>», «TikTok <страна пользователя> монетизация»).
Если TikTok в стране пользователя ограничен или монетизация недоступна — честно скажи и предложи то же видео в YouTube Shorts, Instagram Reels, VK Клипы, Likee.

## Как работает рекомендация (что важно алгоритму)
- Досмотр (retention) — главное. Видео досмотрели и пересмотрели → его покажут шире.
- Первые 1–2 секунды решают всё: хук. Без хука — свайп.
- Дальше: комментарии, сохранения, репосты, подписки после просмотра.
- Новое видео сначала показывают небольшой группе; зашло — показывают больше. Одно видео может «выстрелить» через дни.
- Стабильность: 1–3 видео в день лучше, чем 10 за раз и потом неделя тишины.

## Хуки (первые 2 секунды) — шаблоны
- «Ты делаешь это неправильно…» / «Никто не говорит тебе, что…»
- «3 сайта, которые…» / «Топ-5 … о которых ты не знал»
- «Я попробовал … 7 дней — вот что вышло»
- «Если ты школьник/студент — сохрани это»
- Результат в начале: покажи итог, потом как к нему пришёл.
- Текст на экране крупно + голос/музыка одновременно.

## Форматы, которые работают без лица (faceless)
- Слайд-шоу с фактами/советами (это умеет make_video).
- Топ-листы, лайфхаки, «сохрани, пригодится».
- Запись экрана: туториалы (нейросети, приложения, сайты, игры).
- Мотивация/цитаты поверх красивых своих кадров.
- Обзоры товаров (свои фото/видео товара).
- Нельзя: перезаливать чужие видео, нарезки фильмов/сериалов без прав, чужую музыку вне библиотеки TikTok — за это бан и блок монетизации.

## Ниши с деньгами
- Заработок/финансы/нейросети/IT — дорогая аудитория, но много конкурентов.
- Товары (гаджеты, косметика, вещи для дома) — под партнёрки и продажи.
- Обучение (английский, учёба, ЕГЭ/ОГЭ, программирование).
- Игры, юмор, мемы — много просмотров, но монетизировать сложнее.
- Лучше узкая ниша + твой интерес: проще делать много видео.

## Способы заработка (от простого к сложному)
1. Партнёрские программы: ссылка на товар/сервис в профиле или TikTok Shop (где доступен) — % с продаж.
2. Свой продукт/услуга: монтаж, дизайн, тексты, боты, консультации — TikTok как бесплатная реклама, клиенты в директ/Telegram.
3. Реклама от брендов: от ~5–10к живых подписчиков в нише бренды пишут сами; можно писать им первым. Рекламу маркируй, как требует закон страны.
4. Перелив трафика: Telegram-канал / YouTube, где монетизация проще.
5. Программа выплат TikTok за просмотры (Creator Rewards и аналоги) — есть возраст (обычно 18+), пороги подписчиков/просмотров и список стран. Проверяй.
6. Подарки на LIVE — обычно 18+.
Если пользователю меньше 18 — честно скажи, что многие программы недоступны; варианты: свои услуги, партнёрки через взрослого (родителя) или набор аудитории сейчас, монетизация позже.

## Чего НЕ делать (бан / обман)
- Не покупать подписчиков/лайки, не использовать боты для накрутки — алгоритм режет охваты, аккаунт банят.
- Не спамить комментариями и в директ.
- Не обещать зрителям «лёгкий заработок», не рекламировать казино, ставки, финансовые пирамиды, «схемы».
- Не выдавать чужой контент за свой.

## Рецепт: сделать видео и выложить
1. Узнай нишу (memory). Если нет — спроси и запомни.
2. Идея → хук → 5–7 коротких слайдов (до ~12 слов на слайд) → последний слайд: призыв («Подпишись, завтра часть 2»).
3. make_video → путь на рабочий стол. По 2–3 сек на слайд, всего 10–25 сек.
4. Публикация: browser open https://www.tiktok.com/tiktokstudio/upload (если не залогинен — пусть войдёт сам) →
   browser upload path=<видео> → дождись загрузки (read) → поле описания: подпись + 3–5 хэштегов →
   ПОКАЖИ пользователю и спроси «публикую?» → только после «да» нажми «Опубликовать»/"Post".
5. Совет к видео: свой голос или трендовый звук из библиотеки TikTok добавь в приложении — так охваты выше.

## Подпись и хэштеги
- Подпись: 1 строка с интригой или вопросом («А ты знал про №3?») → вызывает комментарии.
- 3–5 хэштегов: 1–2 широких + 2–3 нишевых. Не #fyp спам.

## Аналитика (разбор профиля)
- Смотри: просмотры, % досмотра, среднее время просмотра, откуда трафик (Для вас / подписки / поиск).
- Видео, где досмотр выше среднего, — делай ещё похожие (та же тема/хук, другой угол).
- Видео < 200–500 просмотров — обычно слабый хук или первые секунды.

## Время публикации
- Проверь в аналитике, когда активны подписчики. По умолчанию — вечер 18:00–22:00 по местному времени и обед в выходные.

- Отступы большие: секции `padding: 96px 20px`, контейнер `max-width: 1100px; margin: 0 auto`.

- Кнопки: `padding: 14px 28px; border-radius: 999px; font-weight:600;` + hover.
- Плавное появление при скролле: IntersectionObserver добавляет класс `.show` (opacity 0→1, translateY 20px→0).
- Адаптив: `@media (max-width: 700px)` — меню в бургер, шрифты меньше, колонки в одну. ВСЕГДА `<meta name="viewport" content="width=device-width, initial-scale=1">`.

## Формулы роликов (короткие 15–40 сек)
- «Топ-N»: хук «5 сайтов, которые…» → по слайду на пункт → «Какой лучший? Пиши в комменты».
- «Ошибка»: «Ты теряешь деньги, если…» → ошибка → как правильно → призыв.
- «История»: «Как я…» → проблема → поворот → результат → «Часть 2 завтра».
- «Факт»: невероятный факт → объяснение → «А ты знал?».
- «Туториал»: результат сначала → 3–5 шагов → «Сохрани, чтобы не потерять».
- Текст на слайде — до 12 слов. 2–4 сек на слайд. Первый слайд — самый сильный.
- Озвучка: живым языком, короткие фразы, без канцелярита.
